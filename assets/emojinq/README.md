# Gazetteer Emojinq subset

These SVGs are the canonical Emojinq glyphs used by the X3 Gazetteer faces.
They are copied from the sibling `CastaliaInstitute/emojinq` project and are
rasterized to 1-bit firmware data by `scripts/generate-emojinq-daily-glyphs.py`.

The glyphs derive from OpenMoji Black and remain under CC BY-SA 4.0. See
`LICENSE-OPENMOJI` and the sibling Emojinq repository for provenance.

## Maya calendar PUA studies

`pua/mayan-calendar/` contains a contemporary brush-symbol set for the
Maya Tzolk'in sacred calendar: 20 day signs and 13 tones. The glyphs use
Supplementary Private Use Area code points `U+F1400–U+F1420` and are symbolic
Emojinq studies, not archaeological reconstructions of Maya hieroglyphs.

The day-name spelling follows the revised Colonial Yucatec forms used in
modern calendrical references. The 260-day count combines 20 day names with
13 numbers.
