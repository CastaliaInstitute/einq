# eInq project status

Updated: 2026-07-29  
Repository: `CastaliaInstitute/einq`  
Public URL: https://einq.castalia.institute/

## Current state

- **Readiness:** Active e-paper platform spanning Xteink X4 firmware, static device pages, generated assets, and a Mynah gateway.
- **Evidence:** Seasonal corner artwork, generated art variants, firmware, tests, deployment workflows, and device documentation are present.
- **Visual policy:** Preserve seasonal and Art Nouveau assets as the project’s visual language. Card art marked placeholder remains a release blocker.

## Release gates

- Confirm the X4 hardware flash path and OTA bundle against a real device.
- Run gateway tests and verify Cloudflare route/secret preservation.
- Replace or explicitly label placeholder card art before a public gallery claim.
